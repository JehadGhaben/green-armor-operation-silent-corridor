# Security Policy

This repository is an intentionally vulnerable, isolated training range.

## Intended weaknesses

Weak credentials, internal clues, and the pivot path are part of the challenge and should not be reported as vulnerabilities in this repository.

## Report a real project issue

Please report issues such as:

- unintended host exposure;
- accidental publication of a CORE service;
- dependency behavior that breaks isolation;
- a challenge path that no longer works as documented.

Never deploy these credentials or configurations in production.
